# Manos Maestras

Landing de oficio artesanal con estética de taller: tonos de arcilla y madera, galería masonry con lightbox, disponibilidad de piezas, encargos por etapas y botón de contacto simulado.

## Ejecutar

Requiere Node.js 20+ y npm. Desde este directorio:

```powershell
npm install
npm run dev
```

Abrir `http://127.0.0.1:5182/landings/manos-maestras/`.

`npm run build` produce la versión autónoma. Para servirla desde el Demos Hub ejecutar `npm run build:hub` y compilar `ideal-it-portfolio`; se publica en `ideal-it-portfolio/public/landings/manos-maestras/`.

Los encargos y el acceso de WhatsApp son simulaciones locales. Las fotografías optimizadas están incluidas en `public/images/`; Google Fonts es opcional y tiene fuentes de sistema como fallback.
