# FixIt Express

Landing de conversión para reparación tecnológica: cotizador en tres pasos, catálogo de servicios, métricas, reseñas rotativas, mapa esquemático y formulario con franja horaria.

## Ejecutar

Requiere Node.js 20+ y npm. Desde este directorio:

```powershell
npm install
npm run dev
```

Abrir `http://127.0.0.1:5184/landings/fixit-express/`.

`npm run build` genera una app estática autónoma. Para publicarla dentro del Demos Hub ejecutar `npm run build:hub` y compilar `ideal-it-portfolio`; los archivos se escriben en `ideal-it-portfolio/public/landings/fixit-express/`.

El presupuesto es un estimado ficticio en pesos argentinos sujeto a diagnóstico. Reseñas, disponibilidad, mapa y formularios son demostrativos y no contactan a un servicio real. La fotografía está incluida en `public/images/`; Google Fonts es opcional y tiene fuentes de sistema como fallback.
